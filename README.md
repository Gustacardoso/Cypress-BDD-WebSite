# Cypress BDD Automation Framework

## Overview
Test automation framework built using Cypress and Cucumber following BDD practices.

## Features
- BDD with Gherkin
- Page Object Model
- Data-driven tests
- CI/CD with GitHub Actions
- Reports generation
- Screenshots and videos
- Test evidence

## Tech Stack
- Cypress
- Cucumber
- JavaScript
- GitHub Actions
- Faker

## Installation

npm install

## Execution

npm run test
